# 브라우저 테스트 시나리오 (AI 수동 실행용)

AI가 MCP 브라우저(cursor-ide-browser)로 직접 열어 수행하는 체크리스트입니다.

## 대상

- **URL**: https://countthefingers.com (또는 로컬 `http://localhost:3000`)

---

## 시나리오 1: 메인 페이지 로드

1. 해당 URL로 이동
2. 페이지가 로드될 때까지 대기(2~3초 또는 snapshot으로 #root 확인)
3. **확인**: 제목에 "Count The Fingers" 또는 "AI 맞추기"·"AI 구분하기" 포함
4. **확인**: `#root` 요소가 존재하고 내용이 비어 있지 않음

---

## 시나리오 2: 루트/앱 영역 표시

1. `browser_snapshot` 으로 현재 DOM 확인
2. **확인**: `#root` 내부에 React/앱이 렌더링된 요소가 있음 (버튼, 링크, 텍스트 등)

---

## 시나리오 3: 게임 시작 플로우 (가능한 경우)

1. 스냅샷에서 "시작", "시작하기", "플레이", "게임 시작" 등 텍스트가 있는 버튼/링크 찾기
2. 해당 요소 ref로 `browser_click` 실행
3. 1~2초 대기 후 `browser_snapshot` 으로 화면 변경 확인
4. **확인**: 퀴즈/이미지 영역 또는 다음 단계 UI가 나타남

---

## 시나리오 4: REAL/AI 선택 (게임 진행 시)

1. "REAL" 또는 "AI" 버튼이 보이면 ref 확보
2. 둘 중 하나 클릭
3. **확인**: 결과 피드백(정답/오답) 또는 다음 퀴즈로 전환

---

## 결과 보고

각 시나리오별로:

- **통과**: 어떤 조건을 확인했는지 한 줄로 기록
- **실패**: 실패한 단계, 스냅샷에서 보인 상태(요소 없음/에러 메시지 등) 요약
- **건너뜀**: (예: 버튼 텍스트가 다름) 이유만 간단히 기록

테스트 완료 후 사용자에게 위 결과를 요약해서 전달한다.
